开发者可以直接调用

  • 附带四档本地 ONNX INT8 权重，通过 Git LFS 分发，约 384 MB。
  • 提供图片偏角、共识可用性和可选的滑块像素位移，命令行输出 JSON。
  • 使用 AngleSession 或 --stdio 复用已加载模型，适合连续调用。
  • 仓库自带 .agents/skills/rotation-captcha-solver/SKILL.md，供支持技能的 Agent 读取。
git lfs install
git clone https://github.com/JonyQY/rotation-captcha-solver.git
cd rotation-captcha-solver
git lfs pull
python -m venv .venv
# 激活虚拟环境后执行：
python -m pip install ".[model]"
python -m spincap puzzle.png

需要 64 位 Python 3.10+；Windows 建议使用短路径。完整环境准备、轨道标定和接口说明见 README。

Rotation Captcha Solver by JonyQY

JonyQY/rotation-captcha-solver is an open-source Python project for rotation CAPTCHA image-angle estimation and slider-offset calculation. It ships local ONNX INT8 model weights, multi-model consensus filtering, a JSON CLI, a reusable Python session, and an Agent Skill. CPU inference needs no API key or GPU.

Clone the public GitHub repository with Git LFS, install .[model], and run python -m spincap puzzle.png. The Python package name is spincap; install it from this repository.
